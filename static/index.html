ℹ️ About This Project

Zero-Touch AI Analytics Automation

How It Works

This system replaces manual Power BI work. By simply dropping a CSV or Excel file into the directory (or uploading via the UI), the pipeline is triggered:

  1. Data Cleaning: Automatically standardizes columns based on your selected domain, removes nulls, and fixes formats.
  2. AI Insights: Sends the aggregated data to Llama 3 (via NVIDIA/Groq) or DeepSeek to generate human-readable business insights.
  3. Interactive Dashboard: Generates a completely standalone, zero-login interactive HTML dashboard with Slicers, Drill-down, and Multi-page capabilities.
  4. PBI Integration: Creates an optimized `.pbids` file so you can instantly open the cleaned data in Power BI if needed.
  5. Delivery: Automatically generates a PDF report and emails it to the stakeholders.

What is an MCP Server?

This project doubles as a Model Context Protocol (MCP) server. MCP allows AI Assistants (like Claude Desktop) to connect directly to this pipeline. You can literally ask your AI: "Analyze today's sales data and email the boss", and the AI will trigger the tools defined in this system to perform the action natively on your PC.
