🔧 How It Works — Step by Step

This system fully automates what Power BI developers normally do manually. You give it data, it does everything else:

  1. Step 1 — Data Upload: Drop a CSV or Excel file into the incoming/ folder (or upload via this UI). The watcher instantly detects it.
  2. Step 2 — Data Cleaning: Automatically normalizes column names based on the domain (Sales, Health, Trading), removes duplicates, fixes dates, handles nulls, and standardizes numeric formats.
  3. Step 3 — AI Insights (Multi-Model Fallback): The cleaned KPIs are sent to an AI engine that tries providers in order:
    • 🟢 NVIDIA NIM (Llama 3.3 70B) → Free 1000 credits
    • 🟢 Groq (Llama 3.3 70B Versatile) → Free, no credit card
    • 🟡 DeepSeek (DeepSeek Chat) → Near-free
    • 🔵 Rule-Based → 100% offline fallback, always works
    If one fails or has no key, it automatically tries the next. Real AI insights, not templates!
  4. Step 4 — Interactive Dashboard: Generates a premium HTML dashboard with cross-filtering slicers, drill-down charts, and a data explorer. Opens in any browser — no login.
  5. Step 5 — Power BI Integration: Creates a .pbids file. Double-click it and Power BI opens pre-connected to the cleaned data — zero Power Query setup needed.
  6. Step 6 — PDF Report & Email: Generates a professional PDF and emails it via Gmail SMTP to any recipient.

🔌 What is an MCP Server?

MCP (Model Context Protocol) is a standard that allows AI assistants (like Claude Desktop) to connect to local tools and software running on your PC.

This project exposes the entire analytics pipeline as MCP Tools. That means you can literally type in Claude:

"Analyze today's sales data and email the report to the boss"

And Claude will call the MCP tools (clean_data, generate_insights, create_dashboard, export_pdf, send_email) to do it all natively on your machine.

Inspired by the architecture demonstrated by Analytical Guy (Atikant Jain) and Data Tutorials.
