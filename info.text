Interview Demo Script (2 Minutes)

Interviewer:

Explain your project.

Answer:

I built an AI-powered analytics automation system using Python, MCP Server, and Power BI. Whenever a new CSV file is placed in a monitored folder, the MCP server automatically triggers data cleaning, generates business insights, refreshes the Power BI dashboard, exports a PDF report, and emails the report to stakeholders. The project demonstrates agentic AI concepts where AI can invoke tools through MCP instead of just generating text.
